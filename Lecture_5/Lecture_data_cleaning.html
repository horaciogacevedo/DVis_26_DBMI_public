Tibbles

We will follow the online version of the book R for Data Science https://r4ds.had.co.nz/tibbles.html

Tibbles are a new object that act as an advanced version of a data frame. The expansion of a data frame traditional structure allows us to clean data faster and more efficiently.

What are the differences?

  • a tibble is not adding a row number
  • a tibble does not change the name of the variables
  • a tibble does not convert strings into factors

There is a nice function to transpose a tibble called tribble. It is useful for getting data entry within your code. Column headings start with a formula (meaning that they should include “~” symbol)

tribble(
  ~x, ~y, ~z,
  #--|--|----
  "a", 2, 3.6,
  "b", 1, 8.5
)
# A tibble: 2 × 3
  x         y     z
  <chr> <dbl> <dbl>
1 a         2   3.6
2 b         1   8.5

Adding rows and columns

The basic function works as follows

df <- tibble(x = 1:3, y = 3:1)
df<-add_row(df,x=4,y=10)

However, it is more efficient using the so-called pipelines that are used widely in tidyverse

df %>% add_row(x = 5, y = 10)
# A tibble: 5 × 2
      x     y
  <dbl> <dbl>
1     1     3
2     2     2
3     3     1
4     4    10
5     5    10

There is more functionality that we can use with *add_row**

# You can specify where to add the new rows
df<-df %>% add_row(x = 6, y = 0, .before = 2)

Something similar is for adding columns

df<-df %>% add_column(z= 1:length(df$x))

There is a very nice overview of what is tidy data

  1. Each variable forms a column
  2. Each observation forms a row
  3. Each type of observational unit forms a table

  mutate(
    week = as.integer(gsub("wk", "", week)),
    date = as.Date(date.entered) + 7 * (week - 1),
    date.entered = NULL
